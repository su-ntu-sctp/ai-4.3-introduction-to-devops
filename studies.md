# 4.3 Self Studies

**Estimated Preparation Time:** 70 minutes

## Task 1 — What is DevOps? (25 minutes)

Watch the following video on DevOps concepts:

- 📹 [What is DevOps? — https://www.youtube.com/watch?v=Xrgk023l4lI]

While watching, refer to **lesson.md Part 1** and pay attention to:
- How DevOps bridges the gap between development and operations teams
- The key principles behind DevOps and why they matter
- The phases of the DevOps lifecycle and how they connect to each other
- How DevOps differs from traditional software delivery approaches

**Guiding Questions:**
1. In your own words, what problem does DevOps solve for software teams?
2. Which DevOps lifecycle phase do you think is most important, and why?
3. How does DevOps relate to Agile — are they the same thing?

## Task 2 — GitHub Flow and Branching (25 minutes)

Watch the following video on GitHub Flow:

- 📹 [GitHub Flow explained — https://www.youtube.com/watch?v=e9lnsKot_SQ]

While watching, refer to **lesson.md Part 2** and pay attention to:

**Guiding Questions:**

2. What happens during a pull request — what is being reviewed and why?
3. How does GitHub Flow support CI/CD practices?

---

## Task 3 — Git Commands Practice (20 minutes)

No video for this task. Refer to **lesson.md Advanced Git Commands section** and practise the following commands in a repository on your machine:

1. View your commit history in a compact format:
```bash
git log --oneline
```

2. Fetch updates from the remote without merging:
```bash
git fetch origin
```

3. Stash your current uncommitted changes, view the stash list, then restore them:
```bash
git stash
git stash list
git stash pop
```

**Guiding Questions:**
1. What is the difference between `git fetch` and `git pull`?
2. When would `git stash` be useful in a real project?
3. What does `git log --oneline` show you that is useful as a DevOps practitioner?

---

## Active Engagement Strategies

- Pause the videos and try to recall the DevOps lifecycle phases from memory before continuing
- After watching Task 2, close the video and try to list the GitHub Flow steps in order without looking
- For Task 3, run each command and note the output — do not just read through the commands
